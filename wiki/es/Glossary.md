# Glosario

| Término | Significado |
|---|---|
| Delta-v | cuánto puede cambiar tu nave su velocidad con el combustible a bordo |
| Velocidad de escape (vₑ) | lo rápido que un motor expulsa el propelente; más alta significa más delta-v por kilo |
| Periapsis / apoapsis | punto más bajo / más alto de una órbita |
| Progrado / retrógrado | a favor / en contra de tu dirección de movimiento |
| Tiempo propio | el tiempo del reloj de tu nave; va más lento cerca de la velocidad de la luz |
| γ (gamma) | el factor relativista; 1 a baja velocidad, 7,1 a 0,99c |
| Sv (sievert) | dosis de radiación; 1 Sv enferma, 6 Sv es mortal |
| Libro de cuentas | el registro de todo lo que se conserva: masa por elemento, energía, momento, tiempo |
| ORB-TLM | el formato estándar de contactos de sensor que leen todas las pantallas de radar |
| Huella de física | un hash del código de reglas; huellas iguales = combates justos |
| Punto de anclaje | un lugar del casco donde va una pieza y que se puede mover |
| Saqueador | dron hostil no tripulado que ataca en oleadas |
