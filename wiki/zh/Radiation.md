# 辐射

有三种辐射会到达你的船员。剂量以希沃特（Sv）计：短时间内超过 **1 Sv** 船员会生病；**6 Sv** 致死（[[生存|Survival]]）。

| 来源 | 典型剂量 | 如何阻挡 |
|---|---|---|
| 宇宙射线（银河） | 深空每天 1.8 mSv，地球磁场内 0.4 | 厚屏蔽也只能帮一点 |
| 太阳风暴 | 数小时的极高剂量，越靠近太阳越强 | 你与太阳之间的质量、避难所、地球磁场 |
| 你的反应堆 | 取决于它的大小 | 距离，以及中间的质量（阴影屏蔽） |

## 以 g/cm² 计的屏蔽

屏蔽按单位面积的质量计算：g/cm²。船体提供 2；铝板和聚乙烯衬层各加 5（聚乙烯按 1.6 倍计，因为氢更能阻挡粒子）。水墙利用你携带的水最多增加 20 g/cm²（[[部件|Parts]]）。

## 太阳风暴

风暴预警大约提前一小时。按 **Z** 进入**风暴避难所**：船员躲到水箱和燃料箱后面（最多 15 g/cm²）。只有储箱紧挨乘员舱时才能完全生效，这在[[飞船建造器|Ship Builder]]中设置。风暴强度随你与太阳距离的平方衰减（定律 6），在地球磁场内只受到 5 % 的剂量。主动磁屏蔽可将风暴削减 90 %。

## 反应堆

反应堆的剂量随距离平方以及它与船员之间的质量而下降。把反应堆放在飞船尽头，藏在储箱和桁架后面，剂量几乎消失。[[飞船建造器|Ship Builder]]会显示这个数字。

## 研究

屏蔽科技：聚乙烯、水墙和主动磁屏蔽（[[科技|Technologies]]）。

## 辐射带

行星磁场把质子和电子困在辐射带中。在 2 g/cm² 屏蔽后的剂量率：

| 位置 | 剂量 |
|---|---|
| 近地轨道（在辐射带之下） | 辐射带无剂量 |
| 地球内辐射带（距地心 1.6 个地球半径） | 约 90 mSv/天 |
| 地球外辐射带（4.5 个半径） | 约 80 mSv/天（电子：少量屏蔽即可挡住大部分） |
| 出发时穿越两条辐射带 | 约 2 mSv |
| 木星，木卫一轨道处 | 约 33 Sv/天：数小时内致命 |
| 木卫二 / 木卫三 / 木卫四 | 约 5 Sv/天 / 约 0.24 Sv/天 / 约 0.5 mSv/天 |
| 土星（光环吸收粒子） | 最多约 7 mSv/天 |

硬质子按 e^(−ad/15 g/cm²) 被屏蔽削弱，软电子按 e^(−ad/1.5)，木星的高能电子只按 e^(−ad/20)。进入辐射带时会有警报。木卫四是在木星停靠的安全地点。

## 太阳活动周期

太阳活动以约 11 年为周期起伏。在太阳活动极大期附近，质子风暴的频率约为极小期的四倍，而且更强；但太阳更强的磁场会把银河宇宙射线推开：宇宙射线剂量在极大期约低 25%，在极小期约高 25%。游戏开始于极大期刚过不久；生命保障读数（H）显示当前活动水平以及下一个极大期或极小期何时到来。

## 飞行计算机的比特翻转

高能粒子穿过存储芯片时可能翻转一个比特。在辐射带或太阳风暴中，普通飞行计算机可能崩溃重启，自动驾驶随之断开（大约每小时每 200 mSv/h 的照射发生一次：穿越地球辐射带时很少见，在木卫一附近每小时都会发生）。抗辐射加固计算机（🏭 制造 → **飞行计算机**：特殊芯片、纠错内存、三重表决）则不受影响。
