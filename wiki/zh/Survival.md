# 生存

你的船员需要**氧气、水和食物**，**舱温低于 45 °C**，**清除 CO₂**（需要电力），以及对**辐射**的防护。驾驶舱的生命体征条会逐项显示：

| 体征 | 危险 |
|---|---|
| ❤ 船员 | 降到 0 % 时船员死亡 |
| 🛡 船体 | 降到 0 % 时飞船被毁；破损（BREACH）会泄漏氧气 |
| 🫁 O₂ · 💧 水 · 🍞 食物 | 剩余天数；耗尽后伤害很快（氧气）或较慢（食物） |
| 🌫 CO₂ | 超过 0.6 kg 有毒；电池耗尽时会积累 |
| 🌡 舱温 | 超过 45 °C 船员过热 |
| ☢ 剂量 | 超过 1 Sv 生病，6 Sv 致死；太阳风暴是最大风险 |
| 🔋 电力 · 🔧 系统 | 没电时生命维持停止；故障部件需要备件包 |
| ⚠ 威胁 | 来袭导弹、袭击者、会撞上星球的轨道 |

**撞击地面：**以相对地表超过 **10 m/s** 的速度接触行星或卫星就是坠毁：飞船被毁，任务结束。速度更慢则是着陆（之后还能再起飞）。

**太阳风暴**会提前约一小时预警：按 **Z** 躲到水箱和燃料箱后面，或者留在地球磁场内。**微流星体**会磨损部件，有时会击穿船体。循环式生命维持（需研究）可以把水重新变成氧气。

## 你的乘员（👩‍🚀 乘员，F3）

你和**两名宇航员** Ada Reyes 与 Kenji Sato 一起飞行。每个人都要呼吸、喝水和进食：每人每天 **0.84 千克氧气、2.5 千克水和 1.6 千克食物**
（再生生命保障可回收大部分水和氧气）。开局时你有**两人一年的补给**（615 千克氧气、1,830 千克水、1,170 千克食物），
起始火箭携带 9 吨燃料，因此载着这些补给仍能逃离地球。

每名宇航员有一项**职责**，职责会自动进行：

| 职责 | 作用 | 技能越高越快 |
|---|---|---|
| 🩹 船体修补 | 用**船体补丁包**封堵微流星体破口 | 1 级每个破口 3 小时，5 级 36 分钟 |
| 🔧 维修 | 用**备件包**修复故障和磨损的部件及发动机 | 每小时修复状态的 6% × 等级 |
| 🔬 科研 | 增加研究点数（需要电力） | 每小时 0.5 × 等级 |
| 🛏 休息 | 乘员健康恢复速度加倍 | + 等级 |
| 🧭 驾驶 | 没有自动工作；帮助乘员恢复 | 小幅加成 |

Ada 一开始负责船体修补，Kenji 负责维修，因此只要有补丁包和备件包，破口和故障都会自动处理。**技能**（1–5 级）随在岗时间增长
（120、360、840 和 1,800 小时），也可以用研究点数立即 **📚 训练**（30、60、120、240 研究点）。

**补丁包与备件包：** 船体补丁包每个 4 千克（2.5 千克铁、1 千克碳、0.5 千克硅酸盐）；备件包每个 14 千克。开局有 8 个补丁包和 6 个备件包；
在 🛠 → 🏭 制造 → 补给中制作更多。

### 更多宇航员，更多职责

在地球引力范围内，可在乘员窗口中 **➕ 招募** 新宇航员：花费 2 × 10⁹ J 将其发射上来（作为 🏭 制造 中的任务运行），
到达时已在某项专长上达到 2 级，体重 80 kg。**舱位**取决于生命维持系统：开环 4 人、再生式 8 人、温室 12 人。
每位宇航员都要吃喝呼吸，乘员越多补给消耗越快。**🏠 送回家** 可把一名乘员送回地球（需在地球引力范围内）。
四项新职责让更多乘员有活可干：

| 职责 | 作用（按所有担任者的等级累加） |
|---|---|
| 🏭 制造 | 制造功率 +15 % |
| ⛏ 采矿 | 多收集 15 % 开采下来的岩石 |
| 🎯 炮术 | 对飞船和无人机的武器伤害 +10 % |
| ⛑ 医疗 | 每小时治疗 1 %，并更快消除辐射病 |

**🧊 冬眠**（技术*乘员冬眠*，800 研究点）：乘员在假死状态中沉睡。不吃不喝不呼吸，不衰老也不受辐射，职责暂停，
飞船断电，因此不会磨损或故障。这样乘员才能熬过可能长达数百年的比邻星慢速旅程（[[相对论|Relativity]]）。
唤醒（☀）后才能工作或战斗；战斗中无法冬眠。

## 警报从不暂停游戏：🛟 安全减速

警告以通知形式出现，游戏继续运行。取而代之的是 **🛟 安全减速**（在时间控制旁边、实体驾驶舱的开关，或 **F4**；默认开启），
它会留意任何将在**一个游戏日**内害死乘员的情况：氧气、水或食物耗尽，舱室过热，太阳风暴的辐射剂量，船体被摧毁，轨道撞向地面，来袭导弹。
一旦发现，红色横幅会显示是什么、还有多久，并把时间减慢到仍能留给你**大约 5 分钟现实时间**的最快速度。危险解除后，时间会恢复到原来的速度。
在多人游戏中共享时钟无法减速，但横幅仍会提醒你。

## 得分与第二次机会

乘员牺牲时你会获得**得分**：存活天数、离地球最远的距离和最高速度、离太阳最近的距离、技术、发现、开采质量、合同、摧毁的袭击者和乘员训练。
你的最佳得分保存在浏览器中。在单人游戏中你可以 **⏪ 提前 24 小时重新开始**：游戏大约每个游戏小时保存一次快照，带你回到一天前的快照，并使用最慢的时间速度。
