# 合同

按 **9**（手机：☰ → 飞船 → 合同板）查看地球任务控制中心的任务。同时提供三个，根据你的位置挑选；你最多可同时执行三个。每个游戏日会出现新任务。

| 合同 | 完成条件 |
|---|---|
| 抬升轨道 | 你的最低点高于地球上空的目标高度 |
| 逃离地球 | 你的轨迹不再回绕（偏心率 ≥ 1） |
| 进入某个天体的轨道 | 该天体是你的主导天体且你被它束缚 |
| 勘察小行星 | 你距离它 10 km 以内 |
| 开采岩石 | 接受后你已开采了指定数量 |
| 悬赏 | 接受后你已摧毁了指定数量的袭击者 |
| 运送水 | 你带着水进入目标轨道（水会被消耗） |
| 俯冲太阳 | 你进入距太阳的目标距离以内 |
| 发射科学探测器 | 你发往该世界的探测器数据传回给你 |
| 用无人机运回矿石 | 接受后你的采矿无人机已运回指定数量 |
| 光速试炼 | 你达到光速的 1 %（需要 15 项以上科技） |

## 报酬如何发放（以及原因）

奖励遵循[[Stellar Impulse 的定律|The Laws of Stellar Impulse]]，所以没有东西会凭空出现：

- **研究点数**是知识，通过无线电发送。即时到账。
- **能量**由地球的**能量束**传送：只能送达你电池剩余的容量。电池满了就会浪费，所以先腾出空间。
- **物质**（材料、备件、导弹）装在从地球发射的**补给舱**中。它只能在地球引力范围内送达；如果你在远处，它会等待，下次你回来时对接。

提示：把方向相同的合同串起来。*逃离地球* + *进入火星轨道* + *向火星运送水* 只需一次旅程。
