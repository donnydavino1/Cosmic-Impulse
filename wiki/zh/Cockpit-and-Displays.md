# 驾驶舱与显示

你如何看游戏由你决定。这些都不会改变物理，也不会改变传感器能探测到什么：所有玩家得到相同的信息（[[公平竞技与规则|Fair Play and Rules]]）。

## 3D 驾驶舱（默认）

在第一人称视角中，你坐在窗下一个建模的**驾驶舱**前：倾斜的主控制台上有**三块发光大屏**、两块触控面板、一排发光按键，
两侧控制台布满按钮，下方还能看到操纵杆和油门杆。屏幕是实时的（每秒根据飞船数据重绘四次），而且**每块屏幕都是按钮**：
把鼠标移到屏幕上（指针变成手形）然后点击：

| 屏幕 | 显示 | 点击打开 |
|---|---|---|
| **飞行**（左） | 速度、高度、轨道、发动机、推力、时间速度、日期、自动驾驶阶段 | 🧭 导航 |
| **传感器**（中） | 你的雷达显示 | 切换到下一种雷达样式 |
| **系统**（右） | 电池、发电/耗电、乘员回路和高温回路温度、船体、推进剂 | 🌡 热管理（热图和散热器计算器） |
| **乘员**（左下） | 乘员健康、宇航员及其职责、补给天数、维修包 | 👩‍🚀 乘员 |
| **战术**（右下） | 主告警（红色闪烁）或*所有系统正常*、武器、目标、距离 | 下一个目标 |

拖动仍然转动视角；只有不拖动的点击才会按下屏幕。驾驶舱屏幕取代了浮动的仪表盘小部件；右上角的 **🧩 显示小部件** 可以把它们重新显示出来。
顶部栏的 🌡 热量 和 👩‍🚀 乘员 按钮在任何视角下都能打开同样的窗口。在 🎨 自定义 → 驾驶舱风格 中选择其他外观，或按 **🎛 实体控制** 使用开关和仪表控制台。

**按真实硬件打造。** 面板是带接缝、紧固件和喷印编号的磨损喷漆金属；显示器装在带斜边的外壳里，边框上有按键，覆盖着反光玻璃；
侧面控制台上有带护盖的拨动开关、滚花旋钮和背光按键；一根黑色侧杆立在橡胶护套中。光照是物理的：真实的太阳只会从窗户照进来，
你转动时窗框的影子会在控制台上移动，显示器向周围面板洒下青色光，金属反射舱内景象，挡风玻璃会淡淡映出亮着的显示器，
阳光照到时还能看到灰尘和细小划痕，尘埃在光束中飘浮。

## 实体驾驶舱

驾驶舱视图（按 **V**）右上角的 **🎛 实体控制** 按钮会把驾驶舱变成真实的仪表台，而不是漂浮的面板：

| 区域 | 内容 |
|---|---|
| **注意 / 警告** | 12 个警告灯（乘员、船体、O₂、水、食物、CO₂、舱温、辐射、电力、系统、威胁、风暴）：琥珀色 = 注意，红色 = 警告。**总告警**会闪烁，直到你按下它。LCD 显示任务时钟和高度。 |
| **仪表** | 速度、电池、推进剂、氧气、舱温和辐射剂量的指针仪表，带红区 |
| **雷达** | 玻璃后面的圆形 CRT 显示屏；**声呐 / 3D** 切换显示内容 |
| **系统** | 带护罩和指示灯的拨动开关：稳定器、避难所、主动/被动雷达、推力模式、音乐；**时间加速**旋钮 |
| **武器与飞船** | 武器 1–5 和目标的背光按钮、大大的**开火**按钮（光束请按住），以及相机、工程、导航、建造器、作业和合同按钮 |

每个开关和按钮的作用都与其按键完全相同，每个仪表显示的数字也与面板相同：仪表台改变的是你*如何使用*飞船，而不是你能知道什么（[[公平竞技与规则|Fair Play and Rules]]）。

## 驾驶舱风格

🎨 自定义（**K**）→ **驾驶舱风格**：

| 风格 | 外观 |
|---|---|
| **3D 驾驶舱**（默认） | 带实时可点击屏幕的建模控制台：见上文 |
| **实体** | 真实仪表：见上文 |
| **写实** | 带边框和螺丝的哑光仪表面板，带支柱的舷窗框 |
| **Neo 玻璃** | 半透明面板，发光边缘 |
| **军用** | 深橄榄色面板，琥珀色读数 |
| **复古** | 带扫描线的绿色荧光屏，1970 年代风格 |
| **经典** | 朴素的平面面板 |

面板是**组件**：按 **I** 移动、调整大小、添加或移除，按 **J** 切换布局。见[[自定义|Customization]]。

### 3D 驾驶舱框架

第一人称视角中，窗框、遮光罩、侧壁、顶部开关面板、扶手和平视显示器玻璃都是**真实的 3D 几何体**，由真实的太阳照亮
（真实的方向和亮度，进入行星阴影时变暗），环绕地球时还有蓝色的地球反照光，仪表灯为暖色，出现严重警报时变红。
你的头部会随着感受到的推力向后摆动，框架会随着发动机震动和受到攻击而抖动。在 🎨 自定义 → 驾驶舱风格中开关（*3D 驾驶舱框架*）。
*经典*风格保留平面框架。

## 雷达显示

| 显示 | 内容 |
|---|---|
| **3d**（默认） | 接触点按真实高度显示，带距离环、高度柱和运动轨迹；拖动可旋转 |
| **声呐** | 像老式潜艇雷达一样旋转的波束：只有波束扫过时接触点才更新，随后逐渐消失 |
| **全息** | 带高度柱的全息圆盘 |
| **扫描** | 经典荧光扫描，俯视 |
| **网格** | 带距离标签的战术网格 |
| **列表** | 简单列表：类型、距离、接近速度、误差 |
| **极简** | 一个圆环和彩色圆点 |

更好的传感器让声呐转得更快、看得更远（[[传感器与雷达|Sensors and Radar]]）。

## 写实外观中的行星

在写实外观（🎨 自定义）下，行星表面有起伏，在晨昏线附近的低角度阳光下尤为明显；地球海洋在太阳反射处闪光，夜半球可见城市灯光。

**高时间速度下不再闪烁：** 进出行星阴影时光线会平滑过渡；当昼夜循环快于几秒现实时间时，画面显示整圈轨道的平均光照（阴影更柔和、城市灯光更暗），
而不是闪烁。电力和热量仍按真实的瞬时阴影计算。

## 自己动手

驾驶舱风格和雷达都是代码：`ORB.cockpit.register(名称, {frame, label})` 加 CSS，以及 `ORB.radar.register(名称, 绘制函数)`。见 `docs/MODDING.md` 和[[打造你自己的 Cosmic Impulse|Build Your Own Cosmic Impulse]]。
