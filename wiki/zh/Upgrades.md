# 升级

你安装的每个部件都能从 **Mk I** 精炼到 **Mk V**。打开[[飞船建造器|Ship Builder]]（按 **7**），选择一个模块，点 **⬆ 升级到 Mk …**。升级和建造部件一样，是制造器的一项任务（[[飞船与工程|Ship and Engineering]]）。

## 每一级提升什么

| 部件类型 | 高于 Mk I 的每一级 |
|---|---|
| 船架 | g 额定值 +15 % |
| 电池、飞轮、超级电容 | 储能与功率 +20 % |
| 发电机与反应堆 | 功率 +15 %，辐射 −15 % |
| 散热器 | 散热面积 +15 %，最高温度 +3 % |
| 生命维持 | 耗电 −10 % |
| 屏蔽 | 屏蔽 +15 %，耗电 −10 % |
| 实验室 | 研究速度 +25 % |
| 制造器 | 制造功率 +25 % |
| 传感器部件 | Mk III 和 Mk V 时传感器等级 +1，耗电 −10 % |

Mk V 实验室的研究速度是 Mk I 的两倍；Mk V 反应堆功率多 60 %，辐射少 60 %。

## 花费

- **材料：**部件自身配方的一半，乘以当前等级。
- **能量：**每升一级翻倍。
- **知识：**Mk III 需要已掌握 8 项科技，Mk IV 需要 12 项，Mk V 需要 16 项（[[科技|Technologies]]）。

## 为什么升级后的部件更重

升级所用的材料被装进了部件，所以部件质量正好增加这么多。没有东西凭空出现（[[Cosmic Impulse 的定律|The Laws of Cosmic Impulse]]，定律 3）。更重的部件会改变[[飞船建造器|Ship Builder]]中的质心和转向时间，所以升级是一种取舍，而不是白赚。

## 发动机

发动机有自己的改进：研究**发动机改进 Mk II** 和 **Mk III**，然后在 🛠 → 🚀 发动机 中升级每台发动机。见[[发动机|Engines]]。
