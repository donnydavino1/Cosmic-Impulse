# 相对论

低于每秒几千公里时，牛顿力学就够了。接近光速（c = 299,792 km/s）时，Cosmic Impulse 改用狭义相对论，见[[定律 7|The Laws of Cosmic Impulse]]。

## 伽马

洛伦兹因子 γ = 1 / √(1 − v²/c²) 表示相对论效应有多强：

| 速度 | γ | 飞船上一年相当于家里的 … |
|---|---|---|
| 光速的 1 %（3,000 km/s） | 1.00005 | 1 年零 26 分钟 |
| 光速的 10 % | 1.005 | 1 年零 2 天 |
| 光速的 50 % | 1.155 | 1.16 年 |
| 光速的 90 % | 2.29 | 2.3 年 |
| 光速的 99 % | 7.09 | 7.1 年 |
| 光速的 99.9 % | 22.4 | 22 年 |

## 两个时钟

游戏显示**游戏时间**（太阳系的时钟）和**飞船时钟**（你的固有时）。接近光速时，船员按飞船时钟变老、吃饭和呼吸，所以快船走同样的路程需要更少补给（[[生存|Survival]]）。

## 能量之墙

动能是 (γ − 1)·m·c²。一艘 100 吨的飞船在光速 10 % 时约有 4.5×10¹⁹ J，大约相当于当今全世界一个月的能源消耗。在 99 % 光速时约为它的 1,200 倍。这就是只有聚变和反物质驱动才能到达的原因（[[发动机|Engines]]、[[科技|Technologies]]），也是*光速试炼*合同只要求 1 % 的原因（[[合同|Contracts]]）。

## 你看到的

传感器信息也以光速传播，所以远处的东西你看到的是它过去的样子（[[传感器与雷达|Sensors and Radar]]）；探测器数据以光速传回（[[无人机与探测器|Drones and Probes]]）。

## 去比邻星要多久？

比邻星是离我们最近的恒星，距离 **4.25 光年**（268,000 AU）。旅程用时取决于飞船能飞多快，你会看到三个时钟：

| 最高速度 | 宇宙（游戏时间） | 飞船时钟 | 现实时间（最快时间速度） |
|---|---|---|---|
| **0.99 c**（γ ≈ 7.09，反物质） | ≈ 4.3 年 | ≈ **7.3 个月** | 滑行几秒，另加点火时间 |
| 0.24 c（反物质，200 t 燃料） | ≈ 18 年 + 点火 | ≈ 17.5 年 | ≈ 15 分钟 |
| 0.02 c（聚变，400 t 燃料） | ≈ 210 年 + 点火 | ≈ 210 年 | ≈ 40 分钟 |
| 20 km/s（以逃逸速度滑行） | ≈ 64,000 年 | 相同 | ≈ 17 分钟（大部分用于穿越每颗恒星周围的 2,000 AU） |

**深空时间速度**（**1 秒 = 9.5、95 和 950 年**）在距**所有恒星 2,000 AU 以外**时解锁，那里没有什么会快速变化；
在太阳或比邻星 2,000 AU 以内最快为 1 秒 = 1 年，回到这个范围内时间会自动降回。因此任何能离开太阳系的飞船都能在远少于一天的现实时间内到达比邻星；
出发前巡航对话框会显示估计时间。物理在任何时间速度下都相同：积分器只是在引力微弱而平滑的地方迈更大的步子。

出发方法：🧭 导航 → 搜索 *比邻星* → **🚀 星际巡航**。巡航自动驾驶先爬出太阳的引力井（沿运动方向推进，这样推力小的发动机会螺旋向外而不是落向太阳），
然后朝比邻星加速，直到剩余推进剂刚好够制动，接着滑行，最后制动，停在距恒星 2 AU 以内，然后进入环绕它的圆形轨道。若乘员需要超过一年的补给（让他们 **🧊 冬眠**：[[生存|Survival]]）、
热量会限制发动机推力，或你没有惠普尔防护罩抵御奥尔特云尘埃，它都会提醒你。

## 游戏如何计算引力和相对论（精确模型）

**简短回答：** Cosmic Impulse 的运动计算**没有**使用完整的后牛顿（PN）积分器。它使用的是
**狭义相对论 + 牛顿引力**：牛顿的平方反比引力作为一种力，作用在飞船的相对论动量上，所有计算都在一个以太阳为中心的惯性系中进行。
此外，**飞船时钟**包含了**第一阶后牛顿时钟项**（引力时间膨胀，也就是 GPS 卫星需要校正的效应）。以下内容就是代码实际所做的（`game/js/0100-physics.js`）。

### 计算了什么

| 部分 | 游戏中的公式 | 说明 |
|---|---|---|
| 参考系和时间 | 以太阳为中心的惯性系；**T** 是它的坐标时 | 即"游戏时间" |
| 飞船状态 | 位置 **x** 和*固有速度* **u = γv** | u 是每千克静止质量的动量 |
| 洛伦兹因子 | γ = √(1 + u²/c²) | 用 u 表示，因此速度永远不会超过 c |
| 运动 | dx/dT = u / γ | |
| 引力 | du/dT = Σ −GMᵢ (x − xᵢ) / \|x − xᵢ\|³ | 太阳、行星、卫星和比邻星；牛顿定律作用于动量 |
| 推力 | 发动机推力先在飞船自身参考系中计算，再变换：沿运动方向的分量不变，垂直分量除以 γ | 狭义相对论的标准力变换 |
| 燃料、电力、乘员 | 按**飞船时间** dτ 消耗 | 高速飞船按自己的时钟燃烧、呼吸和进食 |
| Δv 上限 | v = c · tanh( (vₑ/c) · ln(m₀/m₁) ) | 相对论火箭方程 |
| 储存的能量 | 增加质量 E/c² | 充满的电池（极其轻微地）更重 |
| 速度上限 | 0.99 c（γ ≈ 7.1） | 游戏设定的限制 |
| **飞船时钟** | dτ = (dT / γ) · (1 + Φ/c²)，其中 Φ = −Σ GMᵢ / rᵢ | **狭义相对论时间膨胀 × 弱场引力项** |
| 传感器看到的 | 目标显示在 d/c 之前所在的位置：x − v·d/c | 一阶光行时 |

行星和卫星沿同一平面内固定的圆形轨道运动（它们吸引飞船，飞船不吸引它们）；小行星沿真实的开普勒椭圆轨道运动。
积分器是**踢–漂–踢蛙跳法**（速度 Verlet）：每一步最多为局部最短轨道时间或穿越时间的 2%（且不超过 10 分钟），
因此轨道在多圈之后仍保持稳定，不会慢慢向内或向外螺旋。

在驾驶舱 **🕐 时钟** 小部件中（用仪表板编辑器添加，按 **I** 键），**飞船时钟速率**显示总速率及其两个因子。在近地轨道上，速度因子约为 1 − 3.3×10⁻¹⁰，
引力因子约为 1 − 1.05×10⁻⁸（大部分来自太阳在 1 天文单位处的引力势；地球贡献 6.5×10⁻¹⁰）。

### 省略了什么，以及影响有多大

| 效应（广义相对论 / 后牛顿） | 在太阳系中的大小 | 为何省略 |
|---|---|---|
| 对*运动*的 1PN 修正（EIH 方程） | 水星近日点每世纪进动 43″；近地轨道的近地点每年约 14″ | 远小于游戏的其他近似（行星圆轨道、行星不扁） |
| 高速物体的额外偏折 | 广义相对论使光的偏折是牛顿的两倍（太阳边缘 1.75″）；接近光速的飞船最多偏折约为牛顿值的 2 倍 | 只对掠过太阳的相对论飞船有意义；以后可以加入 |
| 参考系拖曳（Lense–Thirring） | 地球轨道上每年几十毫角秒 | 可忽略 |
| 引力自身的传播时间 | 引力瞬时作用 | 在广义相对论中，对慢速源几乎相互抵消 |
| 夏皮罗延迟、传感器中的光线偏折 | 雷达延迟最多约 200 微秒；传感器使用直线 | 对游戏可忽略 |
| 引力波 | 太阳–木星系统约 10⁻¹⁶ m/s² 量级 | 完全可忽略 |
| 行星自身的运动 | 用共面圆轨道代替椭圆 | 最大的简化，为了速度而选择；这*不是*相对论问题 |

**一句话总结：** 运动 = 牛顿 N 体引力 + 精确的狭义相对论；时钟 = 狭义相对论 + 第一阶后牛顿（弱场）引力项；
广义相对论的其他效应都远低于你在游戏中能察觉的程度。
