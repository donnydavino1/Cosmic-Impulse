# 推进概念

Cosmic Impulse 中的每台发动机都是真实设计：有的已经飞了几十年，有的在地面测试过，有的是工程师和物理学家的严肃提案。它们都遵循同样的规则：推力 = k × 功率 ÷ 排气速度，以及火箭方程（[[轨道力学|Orbital Mechanics]]）。每台发动机的数据见[[发动机|Engines]]。

| 发动机 | 现实中的状态 | 为什么选它 |
|---|---|---|
| 化学火箭 | 1940 年代起就在飞 | 推力巨大；能迅速离开行星 |
| 离子推进器（栅极） | 已用于许多深空探测器 | 用氙非常省燃料 |
| 霍尔效应推进器 | 已用于数百颗卫星 | 每瓦推力高于栅极离子发动机，更便宜 |
| 电弧推进器 | 已用于通信卫星 | 用氢的简单电推进 |
| 太阳热能火箭 | 地面测试过 | 无需反应堆即可达到化学火箭两倍的排气速度，靠近太阳时最好 |
| 螺旋波磁等离子体发动机 | 在真空舱中测试过 | 用水制得的氢驱动的大功率电推进 |
| MPD 推进器 | 实验室测试过 | 兆瓦级电推力 |
| 核热火箭 | 1960–70 年代地面测试过反应堆，如今有新项目 | 推力强，排气速度是化学火箭的两倍 |
| 太阳帆 | 小型演示航天器上飞过 | 靠近太阳时完全不需要燃料 |
| 电帆 | 设想方案；轨道上做过系绳实验 | 无需燃料，只按 1/距离 衰减，所以远处也有效 |
| 气芯核火箭 | 设想方案 | 30 km/s 且推力巨大 |
| 直接聚变驱动 | 设想方案；小型实验进行中 | 小到能装上飞船的聚变发动机 |
| 磁约束聚变驱动 | 设想方案 | 排气速度达光速的 5 % |
| 惯性聚变脉冲驱动 | 设想方案（星际探测器研究） | 比稳定聚变更轻更强 |
| 束流核心反物质驱动 | 设想方案 | 三分之一光速 |
| 反物质光子火箭 | 理论 | 达到 99 % 光速的唯一途径 |

## 如何选择发动机

- **离开行星**需要推力：化学、核热、气芯。
- **行星间长途旅行**需要排气速度：离子、霍尔、磁等离子体、直接聚变。
- **免费搭车**：太阳附近用太阳帆，外太阳系用电帆。
- **飞向恒星**需要聚变或反物质（[[相对论|Relativity]]）。

你可以拥有多台发动机并随时切换；不用的也会在船尾增加质量（[[飞船建造器|Ship Builder]]）。在 🛠 → 🔬 研究 中研究它们（[[科技|Technologies]]）。
