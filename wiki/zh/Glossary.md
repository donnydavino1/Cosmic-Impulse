# 术语表

| 术语 | 含义 |
|---|---|
| Delta-v | 飞船凭借携带的燃料能改变多少速度 |
| 排气速度（vₑ） | 发动机喷出推进剂的速度；越高，每公斤推进剂带来的 delta-v 越多 |
| 近拱点 / 远拱点 | 轨道的最低点 / 最高点 |
| 顺行 / 逆行 | 沿着 / 逆着你的运动方向 |
| 固有时 | 飞船时钟上的时间；接近光速时变慢 |
| γ（伽马） | 相对论因子；低速时为 1，0.99c 时为 7.1 |
| Sv（希沃特） | 辐射剂量；1 Sv 致病，6 Sv 致死 |
| 账本 | 所有守恒量的记录：按元素的质量、能量、动量、时间 |
| ORB-TLM | 所有雷达显示读取的传感器接触标准格式 |
| 物理指纹 | 规则代码的哈希值；指纹相同 = 公平对战 |
| 挂点 | 船体上放置部件且可移动的位置 |
| 袭击者 | 成波次进攻的敌对无人机 |
