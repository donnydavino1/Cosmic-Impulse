# 飞船与工程

按 **B** 打开 **🛠 工程**（手机：☰ → 飞船）。各标签页：

| 标签 | 用途 |
|---|---|
| 🔧 飞船 | 已安装部件、状态、维修（备件包） |
| 🏭 制造 | 用材料和能量制造部件 |
| 🔬 研究 | 用研究点数解锁科技（共 37 项） |
| 🚀 发动机 | 选择发动机并设定规模；功率与质量相互权衡 |
| 🔫 武器 | 建造武器，发射练习无人机 |
| ⛏ 库存 | 材料、燃料、补给 |
| 📚 图鉴 | 发现与记录 |
| 💾 存档 | 存档槽和新游戏 |
| 🧪 测试 | 作弊：全部解锁、即时订单、免费能量 |

一切都有**质量**，制造需要**能量**，大多数东西还需要**材料**（铁、镍、碳、硅酸盐、铂、水……），可以从小行星开采，或在地球附近时向地球订购。
**设计分析器**会说明限制你飞船的是什么（功率、热量、结构、燃料）以及原因。

**订单**需要时间完成（制造会消耗功率），除非在 🧪 测试中开启*即时订单*。

**每次点击数量：** 在 🛠 工程顶部（以及 🧱 建造器 → 添加部件中）输入你想要的数量，或选择 1、5、10、50 或 100：之后每个建造、获取、制造和订购按钮都会一次完成这么多（材料用完时会停止，并告诉你排队了多少）。每种发动机的燃料还有一个**精确数量**输入框：输入千克数并按回车。

## 📦 货物：船上所有物品

按 **]**、点击顶部栏的 **📦 货物** 按钮，或 🛠 → ⛏ 库存 → *打开货物管理*。它列出你携带的每件散装物品（推进剂、开采的材料、氧气、食物、水、工具包、导弹），
以及它们的质量和占飞船质量的比例。输入数量并点击 **抛弃**（或 **全部**）即可从气闸推出：它保持你完全相同的速度并沿你的轨道漂走，所以你的轨迹不变，
只有质量改变。预览会显示抛弃后的 Δv：扔掉无用重量是提速最便宜的方法。抛弃你需要的氧气、食物或水时会先确认。下方列出固定部件、发动机、武器、太阳能板和乘员的重量，
以及**你的飞船由什么构成**：部件中的铁、镍、碳、硅酸盐和铂（按配方计算）加上你携带的材料。

## 📈 飞行记录仪

按 **;**（或 🛠 → ⛏ 库存 → *打开飞行记录仪*）：用九张图表按游戏时间展示整个任务：距太阳距离、速度、高度、电池、舱内温度、辐射剂量率、推进剂、船体和补给天数。
记录变长时，较早的部分以较低分辨率保存，以便全部显示。将鼠标悬停在图表上可读取该时刻的数值。

## 低温蒸发

热量漏入储罐时，超低温推进剂会慢慢蒸发，气体被排出。🛠 → 🚀 发动机与燃料 → **推进剂储罐** 显示每种燃料的损失，并可改装储罐。以下速率针对地球距离处的纯液氢；漏热按 0.2 + 0.8·(1 AU/距离)² 变化。

| 储罐 | 蒸发 | 代价 |
|---|---|---|
| 多层隔热（标准） | 每天 0.3% | 无 |
| 遮阳罩 + 隔热 | 每天 0.05% | 250 kg |
| 低温制冷机 | 0 | 200 kg + 1 AU 处每吨液氢 150 W（断电时回到 0.3%） |

各燃料按该速率蒸发的比例：液氢 100%，液氘和 D–T 80%，甲烷 25%，氢氧推进剂 15%（约 1/7 是氢），甲烷液氧 8%。氙、氪、氩、水和氨不会蒸发。

## 舰长日志

按 **'**（或 🛠 → ⛏ 库存 中的 📜）。飞船给你的每条消息都会记录下来，附任务日、船员自己的时钟（船上时间，在相对论速度下会变慢）以及你当时的位置。可以搜索、写自己的记录，并把整个日志另存为文本文件。存档中保留最新的 600 条。

同一面板还显示船上每种推进剂的 **储罐容积**（液氢 71 kg/m³，氢氧推进剂约 360，甲烷 423，水 1,000，氙约 1,600）：氢太轻了，同样的质量需要比水大十四倍的储罐。
